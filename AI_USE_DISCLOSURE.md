# AI Use Disclosure — template

Generative AI tools are permitted in the term project, including for code. **Disclosure is required
and is not penalized. Undisclosed use is an integrity matter.** Copy the table below into your final
report as its last section (it does not count toward the 6-page limit), and into your selection + plan
and progress note if you used AI tools for them.

| Tool / model (version if known) | Used for | Extent of involvement |
|---|---|---|
| | | |
| | | |

How to fill it in:

- **One row per tool and purpose.** "Claude — debugging" and "Claude — drafting Section 2" are two rows.
- **Used for** — be specific: *debugging `run_sweep.py`*, *fitting `T = a + b/BW`*, *first draft of the
  related-work paragraph*, *generating the plotting script*.
- **Extent** — say what the tool produced and what you did with it: *suggested a fix, which we rewrote
  and tested*; *drafted the paragraph, which we edited*; *wrote the script, used as is*.
- If you used no generative AI tools, say so in one sentence instead of the table.

You are responsible for everything you submit. "The tool wrote it" does not explain an error, and it
does not explain a result you cannot reproduce.

Course materials (lecture decks, notes, exam questions) must not be uploaded to external AI services.
The brief and starter kit in this repository are public and may be.
